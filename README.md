# 💍 Ramesh & Ramya - Royal Wedding Digital Invitation

A digital wedding invitation web experience designed for **Ramesh T & Ramya HM**.

**Wedding Dates:** October 11 & 12, 2026  
**Hashtag:** `#RAMESHWEDSRAMYA`

## ✨ Features

- **Royal Welcome Screen**: Ornate Kalash emblem, Sanskrit invocation, wax seal entrance, and audio unlock.
- **Top Quick Navigation**: One-tap directions banner to open venue location directly in Google Maps.
- **Couple Photo Carousel**: 5-slide responsive photo gallery with rounded arch frame, subtle Ken-Burns motion, side-by-side couple typography, dot indicators, and swipe support.
- **Full-Screen Lightbox**: Uncropped high-definition photo viewing with next/prev controls, zoom, and counter.
- **Auspicious Muhurtha Countdown**: Live countdown timer to the sacred Muhurtha with Google / ICS calendar reminder sync.
- **Interactive Venue & Directions**: Map view, hall coordinates, train and road travel guides.
- **Interactive Celebrations**:
  - 🎶 Traditional Shehnai melodies audio toggle
  - 🌸 Auspicious rose petal shower toggle
  - 📤 Native Web Share API integration
- **Compact Bottom-Pinned Footer**:
  - Elegant small footprint with golden shimmer top accent
  - Micro-action links (Website, Support Email, WhatsApp)
  - Smooth scroll entrance reveal animation (`IntersectionObserver`)
  - Floating and inline smooth **Scroll-to-Top** buttons

---

## 🚀 Running Locally

Open `index.html` directly in any modern web browser, or serve it with Python:

```bash
# Python 3
python -m http.server 8080
```

Then visit `http://localhost:8080`.
